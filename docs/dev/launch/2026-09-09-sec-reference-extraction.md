## 合规与速率

- 速率固定在每秒约 8 次，低于证监会每秒 10 次的上限。**不要调高。**
- 请求头必须携带联系邮箱，这是证监会公平访问政策的硬性要求。默认值里的地址是本项目
  作者的，换人使用时必须用 `CMOP_SEC_UA` 覆盖。

## 与事前预期的偏差

四条，都是执行推翻了先前的估算或断言。

1. **标的数量从"约一万"修正为 12505。** 先前写入容量基线的是估算。
2. **数据体量从"数十 MB"降一个档次到 6.0 MB。** 这直接坐实了它是参考数据而非
   Bronze 事实，也说明容量基线里这一项此前偏高。
3. **拆股比例的待裁决率实测 9.95%**，1840 条里 183 条需人工裁决。事前没有这个量级的
   预期，它成为数据质量框架的第一批真实用例。
4. **一条断言被推翻并更正，见 `d2fb31d`。** `formerNames` 的 `from` 与 `to` 曾被当作
   更名生效日使用。三项证据否定了这个读法：区间衔接率仅 2.6%、27.4% 的多记录标的存在
   区间重叠、最新一条的 `to` 会漂向当下。它们记录的是名称在 EDGAR 中出现的首末时点。
   **更名的次数与存在性可用，日期不可用。**

## 重跑命令

先跑第一个，第二个依赖它的产出。

```bash
python3 tools/sec-extract/extract-events.py
python3 tools/sec-extract/extract-former-names.py
```

`CMOP_SEC_UA` 覆盖 User-Agent，`CMOP_SEC_RAW` 覆盖输出目录，默认写入
`data/reference/sec/raw/`。**重跑前先确认不会覆盖 2026-09-09 这批原始响应。**
