# User and Operations Guide

This directory will contain the current, public-facing guide for readers,
developers who are new to CMOP, and operators running the platform.

Future documents may cover the platform overview, architecture, setup,
data-generation workflows, backfills, routine operations, and troubleshooting.
They will be created only when the corresponding capability exists.

Guides describe how the platform works today and are updated in place. Design
rationale, rejected alternatives, and historical rollout evidence belong in
[developer documentation](../dev/README.md), not here.

There are no guide documents yet.
